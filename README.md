## ✨ Features

- **Full CRUD** — add, browse, view, update, and delete student records with JSON persistence
- **Search & filter** — by name, email, ID, department, year, and GPA cutoff
- **Multi-level sorting** — by GPA, age, department, or year (ascending/descending)
- **Analytics dashboard** — department stats, top performers, honor roll, grade distribution, at-risk students
- **Set operations** — compare course cohorts with `Intersect`, `Except`, `Union`, `Distinct`

---

## 🧩 LINQ Coverage

| Category | Operators |
|---|---|
| Projection | `Select`, `SelectMany` |
| Filtering | `Where`, `SingleOrDefault`, `FirstOrDefault` |
| Ordering | `OrderBy`, `OrderByDescending`, `ThenBy` |
| Partitioning | `Skip`, `Take`, `TakeWhile` |
| Aggregation | `Count`, `Sum`, `Average`, `Min`, `Max` |
| Quantifiers | `Any`, `All`, `Contains` |
| Grouping | `GroupBy`, `ToDictionary`, `ToLookup` |
| Joins | `Join`, `GroupJoin` |
| Set Operations | `Intersect`, `Union`, `Except`, `Distinct` |
